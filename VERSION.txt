MendTech OS v13 (Field Ops)

Zoho One stays the system of record. MendTech OS is the field layer.

Roles:
- Owner (master code unlocks inspections + quote approval)
- Admin
- HR
- Supervisors
- Workers
- Drivers
- Outsourced (temporary, expiring access)

New in v13:
- MendTech OS design: navy/teal sidebar shell, KPI cards, live progress bars
- Owner Command Centre dashboard with real KPIs and an action feed
- My Field Day: phone-style approved-scope-only day view for workers/drivers
- Quotes register: Draft -> Sent -> Approved -> Release Work
- Price privacy: prices visible to Admin and unlocked Owner only
- Approved-scope release creates a job carrying scope text only, never prices
- Inspection quotations now flow into the Quotes register automatically
- Zoho One service status grid (CRM, Books, Projects, People, WorkDrive, Inventory)
- Owner unlock no longer leaks owner tools when switching to another profile
- Quotes tab hidden from Supervisor and HR entirely

Tab access by role:
- Owner (unlocked): Dashboard, Jobs, Job Detail, Inspections, Quotes, Team, Slack, Zoho
- Admin: Dashboard, Jobs, Job Detail, Quotes, Team, Slack, Zoho
- HR / Supervisor: Dashboard, Jobs, Job Detail, Team, Slack, Zoho
- Worker / Driver: My Field Day, My Jobs, Job Detail, Team
