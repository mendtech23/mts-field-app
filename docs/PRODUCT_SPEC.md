# MendTech OS — Product Specification

## Product objective

Create a high-grade UAE technical-services operating system that is simpler for daily field work than Zoho, while maintaining Zoho One as the system of record.

## Modules

1. Owner Command Centre
2. Leads, customers and properties
3. Inspections and evidence capture
4. Quotes and approved-scope release
5. Jobs, sub-jobs and dispatch
6. Zoho Projects execution tracking
7. Worker My Field Day
8. Supervisor control centre
9. HR and people access
10. Outsourced staff temporary passes
11. Products, services and inventory
12. Time, attendance and GPS
13. Photos, documents and signatures
14. Estimates, invoices, VAT and payments
15. Google review requests
16. Slack, WhatsApp and email communication
17. AI command centre and technician copilot
18. Audit, backups and integration monitoring

## Job lifecycle

Enquiry → CRM Lead/Contact → Inspection → Zoho Quote → Owner Approval → Zoho Project/Tasks → Assignment → Worker Acceptance → Travel/GPS → Work/Photos/Updates → Supervisor/Owner QA → Signature → Zoho Books Invoice → Payment → Google Review Request.

## Quotation privacy

- Owner: full price, cost and margin
- Admin: price access when enabled by Owner
- Supervisor: no price by default
- Worker/Outsourced: approved scope, required materials, timing and instructions only
- Draft or sent quotes never release work
- Only an approved quote can generate operational tasks

## Assignment rule

Initially, only the Owner can create, assign, reassign, schedule and dispatch jobs. AI may recommend but cannot execute assignment.

## AC readings

Optional by default. Owner can make readings mandatory for selected diagnostic, gas charging, compressor, AMC or cooling-performance jobs.
